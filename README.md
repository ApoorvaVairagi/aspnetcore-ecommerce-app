# 🛍️ ASP.NET Core E-Commerce Application
A full-featured e-commerce web application built using ASP.NET Core MVC, Entity Framework Core, and ASP.NET Core Identity. Developed by following a real-world project course.

---

## 🚀 Project Overview

This project demonstrates the end-to-end development of a real-world e-commerce platform.  
It includes user authentication, product management, shopping cart, checkout, and order management — all implemented using modern .NET technologies.

---

## 🧠 Learning Objectives

- Build and structure a multi-layered ASP.NET Core MVC project  
- Use **Entity Framework Core** for database operations (CRUD, relationships, migrations)  
- Implement **ASP.NET Core Identity** for authentication and authorization  
- Apply **Dependency Injection (DI)** and **Repository Pattern**  
- Manage data validation, model binding, and view models  
- Deploy and maintain a production-ready web app

---
